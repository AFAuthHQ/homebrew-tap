# AFAuth Homebrew tap

Homebrew formulae for the AFAuth project.

```sh
brew install afauthhq/tap/afauth
```

See [afauth.org](https://afauth.org) and [AFAuthHQ/cli](https://github.com/AFAuthHQ/cli) for the protocol and CLI source.

Formulae here are auto-bumped by [goreleaser](https://goreleaser.com) on each [`afauthhq/cli`](https://github.com/AFAuthHQ/cli) release tag.
